# CodeLedger

CodeLedger is a production-ready MERN Stack coding platform inspired by LeetCode.

## Goal

This project is being built from scratch to understand backend development from first principles instead of following tutorials.

The aim is to understand every line of code, every package, every middleware, every architecture decision and eventually build the complete platform from memory.
